# ไดอารี่คนเห็นผี — CASE 407
https://phum132.github.io/ghost-diary/archive.html#list
เรื่องลึกลับแบบโต้ตอบได้ เล่าผ่านไดอารี่ 14 วันของคนที่อยู่ห้อง 407 อ่านได้ครบทุกหน้า ส่องหลักฐาน แล้วช่วยกันพิสูจน์ใน **SLUR Lab** ว่าผีจริง หรือวิทยาศาสตร์อธิบายได้

- อ่านได้ครบทั้ง 14 วัน แต่บางหน้าล็อกด้วยรหัสที่ซ่อนอยู่ในรูปและเสียง (เข้ารหัส AES-GCM)
- ตัวดูรูปที่ดึงเงา กลับสี หาขอบภาพได้ / เครื่องเล่นเสียงที่เล่นย้อนและดูสเปกโตรแกรมได้ / ไฟ UV หาหมึกล่องหน
- เครื่องมือวิทยาศาสตร์ 9 ชิ้น: ผีอำ, ผีถ้วยแก้ว, ไฟผีกระสือ, infrasound 19 Hz, pareidolia, birthday paradox, ก๊าซ CO, Brocken spectre, ทฤษฎีของเบย์
- กระดานหลักฐานส่วนตัว แชร์เป็นลิงก์ได้ และห้องสืบสวนผ่าน giscus

ทำด้วย HTML/CSS/JavaScript ล้วน ไม่มี build step ภาพ 3D ใช้ three.js
